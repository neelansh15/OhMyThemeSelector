Why it's different

Live, in your shell

omts is a function in your current shell, so every theme is genuinely loaded while you browse. It's not a screenshot.

No reload

Enter keeps the theme you already see and saves it. Esc puts your previous theme back.

Safe edits

Changes only the ZSH_THEME line, follows symlinked dotfiles, keeps a backup, and refuses to write a file that fails zsh -n.

Type to filter

Built-in and custom themes in one list. Start typing a name to narrow it down.

Install

  1. Clone it as an Oh My Zsh custom plugin:
git clone https://github.com/<you>/OhMyThemeSelector \
  ~/.oh-my-zsh/custom/plugins/omts
  1. Enable it in ~/.zshrc:
plugins=(git omts)
  1. Open a new shell once, then run omts. You never need to reload again.

Keys & commands

↑ ↓Move through themes, loading each one live
